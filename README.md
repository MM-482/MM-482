# MM-482 · WrenchHarbor Studio

I’m building practical tools that make automotive systems easier to explore and understand.

My current project is **Sonata Engine Explorer**: an Android app that connects an interactive engine illustration with component references, service information, tools, and parts research. It started with my 2015 Sonata Limited 2.4L and is growing into a project others can help improve.

I care about clear explanations, useful detail, a clean interface, and an app that works comfortably on phones and foldables. I’m developing it with AI assistance, and the original application code is available under MIT.

## What I’m working on

- Making engine components easier to identify and explore.
- Connecting service references to the right engine, year, and variant.
- Improving Android performance, accessibility, and offline use.
- Building a contributor workflow with documented sources and reproducible checks.

## Collaboration

I’d welcome help with Android development, 3D modeling, interface design, accessibility, testing, and careful review of automotive references. Specific bug reports, source-backed corrections, and practical ideas are especially useful.

The engine model is an evolving illustration. Reference data is labeled by source and applicability; it isn’t a substitute for confirming the correct factory procedure and installed hardware. Private manuals and imported documents are separate from the open-source application code.

**WrenchHarbor Studio** is my project brand. Sonata Engine Explorer is an independent project and is not affiliated with Hyundai.
